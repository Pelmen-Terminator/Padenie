# Падение — архив вселенной (Build 0.4)

Статический сайт для GitHub Pages. Все файлы проекта находятся в корне архива, без вложенных папок.

## Файлы
- `index.html` — страницы архива, статья P-19 и статья корпорации SOUT.
- `styles.css` — оформление.
- `script.js` — навигация, поиск и клиентская расшифровка секретных материалов.
- `padenie-icon.svg` — иконка сайта.

## Публикация
1. Распакуйте архив.
2. Загрузите все пять файлов в корень репозитория GitHub.
3. В репозитории откройте **Settings → Pages**.
4. Выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, затем сохраните.

## Секретные материалы
Секретные материалы хранятся в `script.js` в виде AES-GCM ciphertext. Ключ выводится в браузере из введённого кода посредством PBKDF2-SHA-256; код доступа не хранится в открытом виде в файлах сайта. При завершении сеанса расшифрованный текст удаляется из интерфейса.

Это клиентская защита для скрытия содержания от случайного просмотра, а не абсолютная безопасность. Публичный репозиторий не подходит для хранения настоящих секретов: пользователь, имеющий сайт и время на анализ, может пытаться подобрать код или извлечь данные из браузера после расшифровки. Для настоящей авторизации требуется сервер.

## Состав разделов
Главные герои, второстепенные персонажи, антагонисты, локации, аномалии, организации, сюжет, документы, предметы, секретная информация и «Временные Ветки». Статья P-19 доступна из цепочки «Аномалии → Бактериальные аномалии → P-19». Статья о SOUT открывается из категории «Организации».
